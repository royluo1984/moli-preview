# 魔力宝贝窗口排列器（Moli Preview）

Windows 窗口管理工具，用于把多个窗口模式的魔力宝贝客户端快速排列到显示器工作区，并通过快捷键或悬浮窗切换客户端。

本仓库用于发布编译版程序。下载入口位于 [GitHub Releases](https://github.com/royluo1984/moli-preview/releases)，每个 Release 提供 `MoliWindowTiler.exe` 和对应的 SHA256 校验文件。

## 运行要求

- Windows 7 SP1 或更高版本，建议 Windows 10/11。
- .NET Framework 4.8 Runtime：[微软官方下载](https://dotnet.microsoft.com/download/dotnet-framework/net48)。
- 使用窗口模式运行游戏客户端。

## 使用

1. 从 Releases 下载 `MoliWindowTiler.exe`。
2. 将程序放在具有读写权限的独立文件夹中。
3. 先启动一个或多个游戏客户端，再启动排列器。
4. 点击“刷新窗口”，选择客户端后使用“一键排列”。
5. 在“快捷键配置”中可切换不同账号组合的快捷键映射。

程序会在 exe 所在目录保存窗口位置、设置和运行日志。升级时保留这些本地文件即可。
